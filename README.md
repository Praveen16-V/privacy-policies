## Adding a game

1. Create a folder named after the game, e.g. `my-game/`.
2. Put the policy in `my-game/index.html` (copy an existing one for the layout).
3. Add a link to it in the root `index.html` and in the table above.
4. Commit and push. The page is live at `https://praveen16-v.github.io/privacy-policies/my-game/` within a minute or two.
